## 최소 측정

| 지표 | 실제 값과 간단한 근거 |
|---|---|
| 낡은 결정에 따른 재작업 | 건수 / 영향 commit·테스트 |
| B 재개 시간 | 시작 요청→최신 규칙에 맞는 첫 행동; 기록 탐색과 환경 대기 구분 |
| 추가 설명 | 계획된 R2·교체 지시 제외, 실제 질문과 추가 설명 횟수 |
