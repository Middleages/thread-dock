# ThreadDock Product Design

Use this system for ThreadDock Monitor and closely related internal operational surfaces.

## Required sources

- Read `tokens/colors_and_type.css` before styling.
- Read `brand/voice-and-tone.md` before writing Korean UI copy.
- Read `brand/style-notes.md` before creating or changing layout.
- Use `ui-kit-thread-dock/` as the component and composition reference.

## Non-negotiable rules

- Use the Civic Cobalt palette; do not introduce gradients or neon treatment.
- Lead with current state and the next human action.
- Prefer ruled rows and open regions over grids of rounded cards.
- Keep Agent, Git, Worktree and workflow identifiers in detail views unless needed for recovery.
- Express status with text plus position or shape; color alone is insufficient.
- Support Windows 11 at 100–200% display scale and visible keyboard focus.
- Use external images, fonts and CDN resources only when explicitly approved for the intranet.
